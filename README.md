# proxispeak
A geospatial proximity audio ecosystem for virtual offices.

ProxiSpeak turns a virtual office into a set of zones, and the zone type decides who can hear whom. In open areas, distance alone sets the volume. In meeting rooms, focus rooms and stages, zone rules override distance. The design borrows ideas from Gather, Kumospace and WorkAdventure, and every rule is stored as data, so the office layout can change without code changes.
